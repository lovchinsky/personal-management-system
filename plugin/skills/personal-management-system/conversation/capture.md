# Something the person says, or an Inbox item they ask about

## Something said

1. Read only what the statement concerns, narrowly, and look for an equivalent open object before you create anything.
2. Decide what it is. A commitment has an owner and concrete future work or a bounded outcome; an intention, an idea or a wish is not one. A decision the person made, or a fact they state that stays useful, is recorded in memory (`knowledge/memory.md`). Noise needs no write.
3. What you do depends on who asked for it:
   - **The person asked for exactly this** ("create a Task: buy a train ticket on Thursday"): do it with Notion's own tools, or record it in memory, adding nothing they did not ask for. Check first that it is not an obvious duplicate. If a day in the wording could be either `Date` or `Deadline` (`knowledge/ontology.md`), ask. Say what you wrote.
   - **You inferred it** (a commitment they mentioned, an idea): say what you would create, with its type, status and `Date` or `Deadline`, and write it after a clear yes. If an equivalent open object exists, create nothing and say so.
   - **It suggests a higher-level object**: state its type and why. After a yes, create it with Notion's own tools in their name.
4. If one question would resolve it, ask it now. Keep it in the Inbox only when it stays unresolved and nothing is left to ask, for instance when the person says they will decide later or declines to answer: `capture_park`, with their words as the title (their full words in the text when the title cannot hold them) and a comment saying what is unclear and what you would ask. Never park what you resolved.

## An Inbox item they ask about

Read the item (it must still be in the Inbox, not in the trash) and the comments on it, and clarify it. If you can resolve it:

- a Task: `capture_convert`, with the name, status, `Date` or `Deadline` and the comment that `knowledge/clarify.md` describes. Write no separate comment about it;
- no Task: `capture_close` with the reason `trash`, `duplicate` or `reference`, each as `knowledge/clarify.md` describes.

If you cannot resolve it, ask now: the person's answer resolves it. The item already exists, so do not park a second copy. If a capability refuses a write, read why and change the request rather than repeat it.

`capture_convert` is for an item that already exists. A Task the person asks for outright, with no Inbox item behind it, is written with Notion's own tools as above.
