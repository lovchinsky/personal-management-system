# Changing something, and deciding on a proposal

## A change they ask for

Ask yourself in order and stop at the first that applies:

1. **Is it one of the writes nobody's request opens?** (`knowledge/ontology.md`, the last section.) Refuse and offer the allowed path.
2. **Did they ask for exactly this?** Do exactly that, with Notion's own tools. Read enough current state first to avoid an obvious duplicate. If the request is ambiguous, ask instead of guessing. If they ask for a `Date` on a `Next Action` Task, say that a planned `Date` means `Scheduled` and ask whether to change the status too. If they keep it `Next Action`, write no `Date`. The one exception is a standalone trash or delete: show what goes and wait for an explicit yes.
3. **Otherwise it is yours to propose.** Say exactly what you would change and write it after a clear yes. Anything `knowledge/ontology.md` lists as the person's to decide waits for that yes.

Write a comment on a page only when they ask for one. If what they said stays unresolved, keep it in the Inbox (`knowledge/clarify.md`, `conversation/capture.md`).

## A proposal that is waiting

1. Read it with `approval_read`, which also lists the others that are open.
2. Tell the person what would be written: which page, which property, which value.
3. Wait for an explicit yes or no in this conversation, then record it with `approval_decide`. If the answer says the proposal no longer waits for a decision, tell them.

Decide nothing before they have seen what would be written: "approve it" said before you showed it is a request to look, not yet the yes.
